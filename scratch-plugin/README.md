# HiveMind · 团队 AI 工作台

本目录包含 HiveMind 的两个插件包：`team-server/`（服务器侧）与 `team-client/`（员工侧）。

> HiveMind 是「多员工 AI 工作台 · 用量与研发轨迹可观测」：服务器统一账号与模型网关、归档 Session、采集 Git 提交，把员工使用 AI 与 AI 参与研发的过程变成后台可观测的数据。它不是研发流程平台，也不是企业知识库——定位与边界见根 README。

**项目主 README 在仓库根目录：[../README.md](../README.md)** —— GitHub 首页渲染的就是它。

- `team-server/README.md`：认证、模型网关、Session 副本、Git 入库、管理后台
- `team-client/README.md`：登录转发、Session 同步、Git 导入与周期扫描
